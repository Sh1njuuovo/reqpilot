# 审批管理系统

构建一个在线审批管理系统，支持审批申请提交、多级审批流转、进度查询和历史记录导出，以提高审批效率并减少线下沟通。

## 背景

现有业务审批流程依赖线下沟通，效率低。

## 目标用户

- 审批管理员
- 普通业务人员

## 功能需求

### FR-1 在线提交审批申请（P0）

普通业务人员可以填写申请单并提交，系统生成唯一申请单编号。

### FR-2 多级审批流转（P0）

系统支持配置多级审批流程，申请单按照配置的规则自动流转至各级审批人。

### FR-3 审批进度查询（P0）

用户可查询自己提交的申请单的当前审批状态和进度。

### FR-4 历史记录导出（P1）

管理员可导出审批历史记录，支持常见格式（如CSV、Excel）。

### FR-5 审批流配置（P0）

管理员可以配置审批流程，包括审批节点、审批人、流转条件等。

### FR-6 幂等提交（P0）

系统必须支持幂等提交，防止重复申请，重复提交时返回已有申请单。

### FR-7 提交失败自动重试（P1）

当提交失败时，系统自动重试，确保提交成功。

### FR-8 列表分页加载（P1）

列表查询支持分页，超过100条时分批加载。

## 权限

- 管理员可配置审批流并查看全部数据
- 普通用户只能查看自己提交的记录

## 非功能约束

- 系统应保证高可用性，提交失败自动重试。
- 系统应支持并发访问，保证数据一致性。
- 系统应提供良好的响应速度，列表查询分页加载。
- 系统应保证数据安全，权限控制严格。

## 数据模型

### 申请单

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| 申请单编号 | string | 是 |
| 申请人 | string | 是 |
| 金额 | number | 是 |
| 审批状态 | enum | 是 |
| 提交日期 | date | 是 |

## 页面信息架构

- **提交审批申请**（page-1）：状态 [default、error、success]；组件：form
- **审批进度查询**（page-2）：状态 [default、empty、error]；组件：table
- **审批流配置**（page-3）：状态 [default、empty、error]；组件：form、table
- **历史记录导出**（page-4）：状态 [default、error]；组件：button

## 验收标准

- 管理员可完成审批流配置并生效
- 用户提交后可查询到进度
- 重复点击提交不会产生重复单据

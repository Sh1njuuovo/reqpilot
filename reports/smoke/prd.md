# 支持在线提交审批申请需求说明书

支持在线提交审批申请

## 背景

现有业务审批流程依赖线下沟通；效率低

## 目标用户

- 审批管理员与普通业务人员

### FR-4 审批状态（P1）

提交日期

### FR-6 列表查询需要分页（P1）

列表查询需要分页

### FR-7 用户提交后可查询到进度（P1）

用户提交后可查询到进度

### FR-8 重复点击提交不会产生重复单据（P1）

重复点击提交不会产生重复单据

## 权限

- 角色权限：管理员可配置审批流并查看全部数据

## 非功能约束

- 普通用户只能查看自己提交的记录
- 必须支持幂等提交
- 超过 100 条分批加载

## 数据模型

### 核心业务数据

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| 申请单编号 | string | 是 |
| 查看自己提交的记录申请人金额 | number | 是 |
| 审批状态提交日期 | date | 是 |
| 金额 | number | 是 |

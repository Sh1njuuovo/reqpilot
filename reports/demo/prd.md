# 审批管理系统

构建在线审批管理系统，支持审批申请提交、多级审批流转、进度查询、历史记录导出及审批流配置，提升审批效率。

## 背景

现有业务审批流程依赖线下沟通，效率低。

## 目标用户

- 审批管理员
- 普通业务人员

## 功能需求

### FR-1 在线提交审批申请（P0）

普通业务人员可在线填写并提交审批申请，包含申请单编号、申请人、金额、审批状态、提交日期等字段。

### FR-2 多级审批流转（P0）

系统支持多级审批流程，根据配置自动流转至相应审批人。

### FR-3 审批进度查询（P0）

用户可查询自己提交的审批单的当前进度和状态。

### FR-4 历史记录导出（P1）

管理员可导出审批历史记录，便于存档和分析。

### FR-5 审批流配置（P0）

管理员可配置审批流程，包括审批节点、审批人、条件等，以适应业务变化。

### FR-6 幂等提交（P0）

系统支持幂等提交，防止重复申请，重复点击提交不会产生重复单据。

### FR-7 提交失败自动重试（P1）

提交失败时系统自动重试，确保申请提交成功。

### FR-8 列表分页加载（P1）

列表查询需要分页，超过100条分批加载，提高性能。

## 权限

- 管理员可配置审批流并查看全部数据。
- 普通用户只能查看自己提交的记录。

## 非功能约束

- 系统必须支持幂等提交，防止重复申请。
- 提交失败时自动重试。
- 列表查询需要分页，超过100条分批加载。

## 数据模型

### 审批申请单

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| 申请单编号 | string | 是 |
| 申请人 | string | 是 |
| 金额 | number | 是 |
| 审批状态 | enum | 是 |
| 提交日期 | date | 是 |

## 页面信息架构

- **提交审批申请**（page-1）：状态 [default、error、success]；组件：form
- **审批进度查询**（page-2）：状态 [default、empty、error]；组件：table
- **审批流配置**（page-3）：状态 [default、empty、error]；组件：form、table
- **历史记录导出**（page-4）：状态 [default、error]；组件：button

## 验收标准

- 管理员可完成审批流配置并生效。
- 用户提交后可查询到进度。
- 重复点击提交不会产生重复单据。

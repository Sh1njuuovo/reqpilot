# 在线审批管理系统 PRD

构建一个面向审批管理员与普通业务人员的在线审批管理系统，支持在线提交审批申请、多级审批流转、审批进度查询与历史记录导出，替代低效的线下沟通方式，提升审批效率与可管理性。

## 背景

现有业务审批流程依赖线下沟通，效率低。需要建设在线审批系统，实现申请提交、多级审批、进度查询、历史导出及审批流配置等能力，并保证幂等提交与分页加载等约束。

## 目标用户

- 审批管理员
- 普通业务人员

## 功能需求

### FR-1 在线提交审批申请（P0）

普通业务人员可在线填写并提交审批申请，系统生成唯一申请单编号，支持幂等提交防止重复申请。

### FR-2 多级审批流转（P0）

审批申请按配置的审批流进行多级流转，逐级审批直至完成或驳回。

### FR-3 审批进度查询（P0）

用户可查询自己提交的审批申请进度与当前审批状态。

### FR-4 历史记录导出（P1）

用户可导出历史审批记录，用于留存和统计。

### FR-5 管理员配置审批流（P0）

审批管理员可配置审批流，适配不同业务场景，配置后生效。

### FR-6 管理员查看全部数据（P0）

审批管理员可查看全部审批数据，统一管理和监控。

### FR-7 普通用户查看自己记录（P0）

普通业务人员只能查看自己提交的审批记录。

### FR-8 列表分页加载（P1）

列表查询需要分页，超过 100 条分批加载。

## 权限

- 管理员可配置审批流并查看全部数据。
- 普通用户只能查看自己提交的记录。

## 非功能约束

- 必须支持幂等提交，防止重复申请。
- 提交失败时自动重试。
- 列表查询需要分页，超过 100 条分批加载。
- 系统应保证审批数据的一致性与可追溯性。

## 数据模型

### 审批申请

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| 申请单编号 | string | 是 |
| 申请人 | string | 是 |
| 金额 | number | 是 |
| 审批状态 | enum | 是 |
| 提交日期 | date | 是 |

## 页面信息架构

- **提交审批申请**（page-1）：状态 [default、error、success]；组件：form
- **审批进度查询**（page-2）：状态 [default、empty、error]；组件：table
- **历史记录导出**（page-3）：状态 [default、empty、error]；组件：table、form
- **审批流配置**（page-4）：状态 [default、error、success]；组件：form、table
- **全部数据管理**（page-5）：状态 [default、empty、error]；组件：table

## 验收标准

- 管理员可完成审批流配置并生效。
- 用户提交后可查询到进度。
- 重复点击提交不会产生重复单据。
